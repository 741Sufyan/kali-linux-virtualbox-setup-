# Kali Linux Installation & VirtualBox Setup

## Project Overview

This project documents the installation and configuration of Kali Linux inside Oracle VirtualBox on a Windows 10 host machine.

The purpose of this project is to build a beginner-friendly cybersecurity lab environment for learning Linux fundamentals, networking, and ethical hacking.

## Tools & Technologies

- **Operating System:** Windows 10 Pro
- **Virtualization Software:** Oracle VirtualBox
- **Guest Operating System:** Kali Linux 2026.3
- **Architecture:** AMD64 (64-bit)
- **Virtual Disk:** VDI
- **Network Configuration:** NAT

## Installation Process

1. Downloaded and installed Oracle VirtualBox.
2. Downloaded the official Kali Linux VirtualBox image.
3. Extracted the downloaded virtual machine archive.
4. Imported the Kali Linux virtual machine into VirtualBox.
5. Configured virtual machine settings.
6. Resolved virtual disk path and UUID issues.
7. Started Kali Linux and accessed the system.
8. Verified successful login and desktop access.
